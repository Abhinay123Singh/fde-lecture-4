# fde-lecture-4
In this lecture, I learned how chatbots manage conversations and how LLMs generate responses.

Topics Covered

Conversation history and message roles

System prompts and instructions

Context windows and memory

LLM training vs. prompting

Streaming responses

AI hallucinations and ways to improve reliability

Key Takeaway

Building a reliable AI application is not just about connecting an LLM. It also requires proper context management, memory, validation, and guardrails.
